# BE-01-A 后端最小工程骨架

## 意图
按团队目录规范建立可启动的后端工程，为后续任务接口迁移提供底座。

## 改动
- startup.md：登记后端角色与本轮目标。
- backend/chat.md、tasks.md：登记需求、子任务及验收命令。
- backend/config.py：仅环境变量配置，固定 API 前缀 /api/v1。
- backend/helpers/logging_config.py：应用日志使用 UTC+8。
- backend/main.py：FastAPI 启动入口，监听本机 8000 端口。
- backend/requirements.txt：固定 FastAPI 和 Uvicorn 版本。
- backend/ 各分层目录：建立 Python 包。
- backend/.gitignore：排除缓存、本地环境配置和日志。

## 验证
用户在 Python 3.11.18 环境执行 python main.py。
启动日志显示 Application startup complete。
应用日志时间包含 +08:00。
用户执行：
(Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8000/docs).StatusCode
实际返回：200。
git diff --cached --check：此前检查无输出。
