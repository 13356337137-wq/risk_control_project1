# 竞品调研 · 口径与决策说明（内部，不随文档交接）

《资金流水分析产品工具调研分析（含竞品分析）》已交付：技术调研/ 下，405 行，208 行表格。

## 一、这份调研怎么做的

1. 先分流：把市场拆成四类参与者（文档智能、风控决策、垂直工具、云厂商），否则会拿邦盛这种全行级方案去对标一个文件处理工具，比不出东西。
2. 再定尺子：用「能力层次 L1–L5」作统一坐标。这一步是关键——按功能清单比会陷入"谁都能写 40 项功能"，按层次比才能看出谁停在哪。
3. 最后找空：能力矩阵拉出来，看哪一格普遍偏弱。结论是**证据链回溯**和**审批留痕**两格。

## 二、三条需要你知道的判断

### 1. 解析能力已经不构成差异

云厂商把 OCR 做到按量计费、价格透明。**再投入做"更准的解析"是负期望**。差异点必须上移到校验与报告。

### 2. L3 是分水岭

能不做一致性校验，决定产品是"转换器"还是"核验工具"。达观做到了三要素（结构/结息/余额），银析通做了结息估算，其余多数停在转换。

### 3. 海外的两条路线，国内只有一条

Ocrolus 那类还是吃 PDF；Plaid / Argyle / Finicity 是开放银行直连，**流水真实性由银行背书**，根本不需要核验。

国内短期没有这个基础设施，所以文件路线是唯一选择——这也意味着**真实性核验的投入是必须的，不是可选项**。

## 三、数据可信度（重要）

文档里所有厂商指标我都标了 A/B/C/D 级：

| 数据 | 级别 | 说明 |
| --- | --- | --- |
| "支持数千家银行" | B | 厂商官网口径，无人验证 |
| "13 家以上银行" | B | 同上 |
| "99.7% 准确率 / 48.8 秒" | C | 厂商自述，无第三方复现 |
| "云厂商 3–5 层能力" | D | 第三方横评，可能滞后 |
| "表格抽取差异大于文本抽取" | A | 论文框架，但具体数值我没复现 |

**C 和 D 级数据不能写进对外材料**。

## 四、我没做到的事

1. **没有一手体验**：所有产品都没注册试用过，能力描述全部来自公开页面。银析通有免费额度，其实可以试。
2. **没有定价数据**：国内厂商普遍不公开报价，全按项目制。
3. **没有客户量**：谁都查不到装机量，只能靠营收报道侧面推。
4. **海外产品只看了官网和第三方榜单**，没看接口文档细节。
5. **arXiv 那篇论文我只用了它的评估框架结论**，没读具体排名表。

要做实的话，优先级是：**注册银析通试一次**（成本最低、形态最像），其次找达观的公开白皮书。
