# 我的不可越界（五条，都是这一行最容易犯的错）

1. **抽取只走行内 OCR 服务**：电子件与影像件都调同一个服务接口。不本地另搭识别模型，不把样本发到公网 API——数据不出行是硬约束。
2. **结论必须挂两个版本号**：阈值版本与指标集版本。改阈值只能新增版本，不许覆盖旧版本，否则历史报告无法解释。
3. **线索不是证据**：命中标签（网贷、涉赌、虚拟币）只影响提示与排序，不许直接改变真伪结论。
4. **算不出来就给空值**：任何指标或核验项缺数据时返回 null 并写原因，禁止填 0、禁止估算、禁止用生成式模型补数值。
5. **回不到原页的结论不许出**：每条判断必须能给出交易号、页码、坐标；给不出就不进报告。

# 指标集（数量会变）

当前版本 40 项：A 收入 8、B 负债 8、C 现金流 8、D 行为 8、E 对手方 8。

**这不是承诺**：银行提新指标就加，口径有争议就改，没人用就停用。每版有 `metric_set_version`，单项有 `caliber_version`；两者都只增不改，历史报告按当时版本解释。
