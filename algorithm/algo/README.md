> 这是什么：四层核验、40 项指标、规则命中 · 谁写：算法组 · 何时更新：实现变化时

# 模块

| 文件 | 内容 |
| --- | --- |
| file_layer.py | 文件层 11 项：生成器、增量更新、结构指纹、字体、隐藏文字、覆盖图元、签名、版面、体量、图像混排 |
| content_layer.py | 内容层 10 项：余额链、合计、笔数、期初期末、跨页、参考号、时间分布、金额形态、语义、重复 |
| ledger_layer.py | 账务层 7 项：结息反算、结息日、利息税、费用、到账时延、期末余额、透支 |
| external_layer.py | 外部层 7 项：回单验真、调证、征信、社保个税、行内代发、多份互证、签章 |
| verdict.py | 三态合成与证据组装 |
| metrics.py | 40 项指标与口径版本 |
| hits.py | 规则命中的正则与标签 |
| eval.py | 样本回归与准确率评测 |

# 判定顺序（不许跳层）

```text
file_layer → content_layer → ledger_layer → external_layer

```

前层能定性就不走后面；外部层无数据时降级为「未发现异常但标注」。

# 指标前必做

剔除六类：同名互转、理财赎回申购、贷款放款、信用卡还款取现、退款冲正、他人代付。

# 输出约束

- 不给评分、等级、建议。
- 每条判断挂 rule_code 与位置。
- 指标带 caliber_version。
