# 2026-10-29 · 10 · 外部层接口与降级

## 意图

完成 AL-08「外部层接口与降级」与 AL-14「外部层接口预留」：先定 E1–E7 的适配器协议与结果状态，用占位实现保证无授权时也能跑完主链、不编造外部数据，并把外部不一致接入五态结论。

## 改动

- 新增 `algo/external_layer.py`
  - `EXTERNAL_CHECKS`：E1 电子回单验真、E2 跨行调证、E3 征信交叉、E4 社保与个税、E5 行内代发、E6 多份互证、E7 电子签章 CA；每项写明所需授权或接口。
  - `ExternalContext`：明细 + 账户信息 + 期间 + `materials`；具体材料格式由适配器解释，未定义前不解析。
  - `ExternalAdapter` 协议：`code`、`name`、`check(context)`；`PlaceholderAdapter` 同时实现 `__call__`，可调用且固定返回 `not_configured`。
  - `analyze_external()`：默认 7 个占位适配器；`enabled` 可按编号启用子集；适配器异常按 `unavailable` 降级并写入 detail，不上抛。
  - 合成规则：任一 `inconsistent` → 层 fail、outcome「存在不一致」；全部一致 → pass；部分一致 → limited；一项都拿不到 → unavailable。limitations 逐项写「缺什么 + 未启用」。
- `algo/verdict.py`
  - 在账务层 fail 之后、最终「未发现异常」之前增加外部层分支：`status=fail` 或 `outcome=存在不一致` → 五态「存在不一致」，证据取外部层。
  - 外部层无数据时仍走 final 分支，结论「未发现异常」，reason 为「已完成的核验未发现矛盾；部分检查不可算」，limitations 保留逐项说明。
- `algo/__init__.py` 导出 `analyze_external / ExternalContext / ExternalCheckResult / ExternalAdapter / PlaceholderAdapter / DEFAULT_ADAPTERS / EXTERNAL_CHECKS / default_adapters`。
- 新增 `tests/test_external_layer.py`（12 项）；更新 `tasks.md`（AL-08/14 勾选）、`algo/README.md`（模块表、外部层口径、五态表）、`chat.md`。

## 遗留

- E1–E7 全部未开通：需要客户授权、机构间协议、征信授权、社保个税授权、本行代发接口、多份材料与签章体系；当前只完成接口形状与降级，未接任何真实外部数据。
- `ExternalContext.materials` 没有字段契约，等各接口定义后再补解析；在定义之前不读、不猜。
- E6 多份互证还缺多份流水的装载与账户对齐；E7 还缺证书链校验实现，当前均按占位处理。
- 外部层证据只能由适配器提供；占位适配器不产证据，因此未启用时证据为空，符合「线索不是证据」。
- 真实样本的结论仍是「未发现异常（核验受限）」，与外部层 unavailable 的预期一致，并未因占位而升级为 pass。

## 裁决

- 外部层只做交叉验证，不替代前层：五态顺序固定 file → content → ledger → external，前层能定性就不走外部。
- 无数据不等于一致：未启用、无授权、接口失败分别记录，但都不判 pass；全部未取得时层为 unavailable。
- 外部不一致只说明「与第三方记录不符」，结论用「存在不一致」，不推断伪造主体或主观恶意。
- 适配器异常按接口不可用降级，避免外部系统抖动把整份报告打成失败。
- 占位适配器必须可调用且明确返回未启用，禁止返回空数据或 0，防止下游把占位当真实核验。
