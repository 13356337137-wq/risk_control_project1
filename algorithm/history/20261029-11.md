# 2026-10-29 · 11 · AL-15 样本集

## 意图

完成 AL-15「四类版式 + 两类伪造」，并让样本目录能被 AL-16 评测直接读取：清单、期望值、加载与校验都固化成代码，样本本身用造数生成，不引入真实客户数据。

## 改动

- 新增 `algo/samples.py`
  - 四类版式：`icbc`（借贷标志 + 单列金额 + 余额，跨两页）、`ccb`（收入/支出分列 + 余额）、`cmb`（借贷方向 + 交易金额 + 交易后余额）、`wechat`（收/支 + 金额，无余额）。
  - 两类伪造：`content_amount_tamper`（改金额不改余额）、`file_incremental_overlay`（增量更新 + 白底覆盖后重写金额）。
  - `SampleManifest`：`version、generated_by、cases`；每个 case 带 `id、path、layout、carrier、forgery、expectation{verdict,txn_count,fail_codes}、notes`。
  - `build_sample_set()` 生成 6 份 PDF 与 `manifest.json`；`load_manifest()/load_samples()/validate_manifest()` 校验 id 唯一、路径不越界、文件存在、四类版式与两类伪造齐全。
  - 生成件嵌入 Droid Sans Fallback 子集，固定 Producer/Creator/创建修改时间，页脚写「本页收入合计 / 本页支出合计 / 本页交易笔数」。
  - CLI：`python -m algorithm.algo.samples --out ...` 生成，`--check` 只校验。
- `algo/__init__.py` 导出样本集模型、标签、构建与加载函数。
- 新增 `tests/test_samples.py`（9 项）；更新 `tasks.md`（AL-15 勾选、材料登记）、`algo/README.md`（模块表 + 样本集口径）、`inputs/README.md`、`chat.md`。

## 遗留

- 只有两类伪造；design V1 还列了删行、拼页、换利率、整份重排，后续扩样本时补。
- 干净件没有期初/期末余额，C4 恒跳过；样本只用于解析与算术链回归，不冒充真件。
- F4 结构指纹、F10 体量页密度仍无同版式真件基线，干净件文件层只能到 limited。
- 合成件使用 PyMuPDF 内置 CJK 字体并嵌入子集，体积约 430 KB/份；如果以后要压样本体积，可换更小的中文字体子集。
- 样本与 manifest 放在 `inputs/samples/synthetic/`，被 `.gitignore` 忽略；新环境要先跑生成命令，AL-16 评测入口要显式指向该目录。
- AL-16 尚未实现，当前只验证了加载器与逐份结果；评测指标、抽错归因、准确率口径留到下一轮。

## 裁决

- 样本用生成器而不是提交 PDF：合成件可复现、可审阅，仓库不存二进制，也不会误把造数当真件。
- 清单只放最小期望（五态、笔数、失败编码），不绑定层内部实现；层细节由测试与报告各自断言。
- 干净件必须真的过 C1/C2/C3，不能靠把期望改宽来「通过」；文件层受基线限制记 limited，不强行判 pass。
- 伪造件按可检出性选：改金额验证内容链，增量更新+覆盖验证文件层，两类分别落在不同的五态分支。
- 路径必须相对样本目录且不得越界，清单是外部输入，按不可信处理。
