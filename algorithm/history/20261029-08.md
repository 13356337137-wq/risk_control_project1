# 2026-10-29 · 08 · 规则命中与标签

## 意图

完成 AL-12「规则命中：正则、标签、位置」，让 [LOAN]/[GAMBLING] 等标签有可复现的命中样本，并把标签接进 E04–E06，同时守住「线索不是证据」的边界。

## 改动

- 新增 `algo/hits.py`
  - `LexiconRule`：规则编码、类别、标签、精确词、正则、权重、来源、更新日期、版本；`expr` 按 contract 的 `rule.expr` 拼接。
  - `RuleLibrary`：整库版本 `RULE_LIBRARY_VERSION = 1`，支持 JSON 配置；`detect_hits(..., categories=)` 可按类别筛选。
  - 7 类标签：LOAN、GAMBLING、COLLECTION、CASHOUT、JUDICIAL、INVEST、CRYPTO，对应 9 条规则。
  - 匹配顺序：同一规则先精确词、后正则；字段先摘要、后对手方；一笔交易对同一规则只出一条。
  - 命中带 `page_no、row_no、span_start、span_end、evidence(x,y)`，可回指原页原行；标签按交易对齐输出 `labels`，并给 `tag_counts / tag_txn_counts`。
  - 全半角归一使用 NFKC；长度变化时退回原文，保证 span 不漂移。
- `metrics.compute_metrics` 增加 `hits=` 参数，未显式传 `labels` 时直接使用 `hits.labels`；E06 优先使用 `[CRYPTO]` 标签，未传标签时保留内置词库兜底。
- `algo/__init__.py` 导出 `detect_hits / HitResult / RuleHit / RuleLibrary / LexiconRule / DEFAULT_LIBRARY`。
- 新增 `tests/test_hits.py`（14 项）；更新 `tasks.md`、`algo/README.md`、`chat.md`。

## 遗留

- 词库由算法组归纳，未经组长/风控业务评审；真实样本没有小贷、涉赌、虚拟币交易，召回率未验证。
- 3.5 的 12 类行为模式尚未做成规则表达式；整数、夜间、当日进出已由 D 组指标覆盖，快进快出、拆分、闭环、余额贴零等需要窗口与阈值。
- 规则灰度与按机构开关未做；当前只有整库版本，没有单规则生效范围。
- 投资类词库可能把基金公司工资入账标成 INVEST，属于线索级误报，需业务确认是否收窄。
- 对手方为空的交易只能靠摘要；真实样本 58 笔无对手方，标签覆盖受限。

## 裁决

- 词库宁可漏、不可滥：精确词优先，宽泛词（消费、还款、游戏）不单独成规则，避免普通消费被标成套现/博彩。
- 标签只影响提示、排序与指标，不参与五态合成；五态仍由四层核验证伪决定。
- 命中必须能回指页码、行号与坐标，给不出位置的不进报告。
- 规则库整库版本化；后续新增/修改词条升 `RULE_LIBRARY_VERSION`，不改历史命中。
