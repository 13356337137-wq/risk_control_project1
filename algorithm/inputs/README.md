# 三条规矩

1. **放进来必须登记**，没登记的材料 Agent 不读。
2. 含真实客户信息的先脱敏；能不用就不用，用造数代替。
3. 材料只读：要改结论就改 design 或 tasks，不改材料原件。

# Agent 怎么用

开工先扫本目录与登记表，把新登记的条目写进 tasks 的「材料登记」节，再按材料验证改动。
没有登记表的材料，一律当成不存在。
