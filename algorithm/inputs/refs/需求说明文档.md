# 需求背景
流水是银行零售信贷重要数据，其中，

+ 对于零售信贷业务，可以根据流水分析借款人资产水平、收入水平和稳定性，从交易对手分析出潜在风险，从附言摘要识别出交易风险。

传统流水分析，缺乏自动化分析系统，过度依赖人工，存在的问题：

+ 流水数据一般以pdf、图片等非结构化文档形式，解析效率低下
+ 风险分析依赖专家经验，存在风险识别盲区，难以标准化

在此背景下，需要借助AI技术，实现流水文档解析自动化，并从中挖掘出隐藏风险，提升流水分析的效率和效果。

# 功能需求
## 前端交互
（1）借款人页面：

+ 手工上传pdf和图片格式的流水文档，流水文档支持国有银行和股份制银行流水标准模板

（2）银行工作人员管理页面：

+ 支持任意银行pdf流水模版标注，对于国有银行和股份制银行之外的其他银行流水pdf，文档解析程序可基于标注模版，提升解析准确率

## 后端服务
| 项目 | 说明 | 性能标准 |
| --- | --- | --- |
| 文档解析 | 支持pdf和图片格式的流水文档，流水文档支持国有银行和股份制银行流水标准模板 | + 支持国有行+股份行流水模版<br/>+ 解析和OCR字段解析准确率>99% |
| 真实校验 | 根据印章、流水文档模版、结息、合理性验证等 | |
| 风险分析 | 流水风险分析服务 | |
| 特征衍生 | 基于流水衍生特征入库 | |
| 报告导出 | 导出为pdf | |
