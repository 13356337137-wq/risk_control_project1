# 任务清单
将开发任务拆解为可执行的 Vibe Coding 任务块，建议按顺序让 AI 生成代码。

## 阶段一：工程初始化与数据模型 
- [ ] **Task 1.1**：创建 FastAPI 工程目录骨架 (`routers`, `services`, `schemas`, `config.py`, `main.py`)。
- [ ] **Task 1.2**：根据 `design.md`，在 `schemas/risk.py` 中定义 `TransactionSchema`、`MetricsSchema` 和 `ReportResponseSchema`。
- [ ] **Task 1.3**：编写 `main.py`，配置全局统一响应拦截器（捕获异常并返回 `{code: 500, message: err}`），启动 FastAPI 服务。

## 阶段二：核心服务逻辑开发 
- [ ] **Task 2.1 (Mock 解析)**：在 `services/parser_service.py` 中编写 `mock_parse_file(file)` 函数。读取本地一份 `mock_data.csv`，转换为 `TransactionSchema` 列表。
- [ ] **Task 2.2 (指标计算)**：在 `services/risk_service.py` 中编写 `calculate_metrics(df)`。利用 Pandas 计算 7 个基础指标（注意空值处理和精度四舍五入）。
- [ ] **Task 2.3 (规则评分)**：编写 `evaluate_risk(df)` 函数。实现正则敏感词匹配（[LOAN], [GAMBLING]），计算并返回综合评分（0-100）、风险等级（高/中/低）及四维雷达分数。
- [ ] **Task 2.4 (数据聚合)**：编写 `generate_report_data(df)` 函数。按月份 `groupby` 聚合收支数据生成 `trendData`，组装最终报告 JSON。

## 阶段三：接口路由与联调 
- [ ] **Task 3.1**：在 `routers/report.py` 中实现 `GET /api/tasks/{taskId}/report` 路由，调用 `services` 层的逻辑。
- [ ] **Task 3.2**：启动 Uvicorn，使用 Swagger UI (`/docs`) 或 Postman 进行接口测试，确保返回 JSON 完全符合 `design.md` 的契约。
- [ ] **Task 3.3**：编写 `README.md`，说明如何启动服务、测试接口。

# 任务依赖
- Task 1.1 必须最先完成。
- Task 1.2 (数据模型) 必须在 Task 2.1、2.2、2.3 之前完成，因为函数依赖数据模型。
- Task 2.4 (聚合) 依赖于 Task 2.2 和 2.3 的计算结果。
- Task 3.1 (路由) 依赖于所有 Service 层代码开发完毕。
- Task 3.2 (接口联调) 必须在前端开始联调前完成。

# 验收标准
1. **代码跑通**：执行 `uvicorn main:app --reload` 无报错，服务正常运行。
2. **接口契约**：请求 `/api/tasks/123/report` 返回的 JSON 字段名、嵌套层级与 `design.md` 中的示例 100% 一致。
3. **指标精度**：手工计算结果与接口返回结果一致，金额严格保留 2 位小数，无浮点误差（如 58000.00）。
4. **标签准确**：当摘要包含“网贷/小贷”时，返回的 `riskTags` 必须包含 `["LOAN"]`；包含“博彩/赌”时包含 `["GAMBLING"]`。
5. **时间正确**：输出日期格式严格为 `YYYY-MM-DD` 和 `YYYY-MM`，且无时区偏移问题。
