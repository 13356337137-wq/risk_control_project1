# 功能模块
本算法模块（MVP版）按流水线划分为以下四个核心功能模块：
1. **Mock OCR 解析模块**：模拟接收文件与解析过程，输出符合标准格式的结构化流水数据（DataFrame/List）。
2. **核心指标计算模块**：基于 Pandas 对流水数据进行清洗、聚合，计算 7 个指定基础风控指标。
3. **规则引擎与评分模块**：对摘要（summary）进行正则敏感词匹配，并基于规则输出综合评分、风险等级与四维雷达图数据。
4. **报告数据聚合模块**：将指标、评分、标签、趋势图数据、明细数据组装为最终前端所需的 JSON。

# 系统架构
本模块采用 FastAPI 标准的三层架构：
- **路由层 (routers)**：接收 HTTP 请求，校验参数，返回统一响应结构。
- **服务层 (services)**：核心业务逻辑，包含 `parser_service`（解析）、`risk_service`（指标与评分）、`report_service`（报告组装）。
- **数据模型层 (schemas)**：使用 Pydantic 严格定义 API 的请求体与响应体。
数据流转：前端请求 -> routers 接收 -> services/parser_service (Mock) -> services/risk_service -> services/report_service -> 返回 JSON。

# 前端设计
算法侧不涉及前端 UI 开发，仅通过 API 契约向 React 前端提供以下数据结构：
1. **趋势图数据**：`trendData: [{"month": "2026-01", "income": 10000, "expense": 5000}]`，供 ECharts 折线图使用。
2. **雷达图数据**：`radarData: [{"dimension": "稳定性", "score": 80}, ...]`，共 4 个维度。
3. **明细数据**：需提供 `riskTags` 数组（如 `["LOAN", "GAMBLING"]`），前端据此标红敏感交易。

# 后端设计
- **`config.py`**：存储环境变量（如 Mock 延迟时间）。禁止硬编码。
- **`services/parser_service.py`**：读取本地静态 Mock 数据（CSV/JSON），返回标准化流水列表。
- **`services/risk_service.py`**：
  - `calculate_metrics(df)`：使用 Pandas 计算 7 个基础指标。
  - `evaluate_risk(df)`：使用 `re` 模块匹配敏感词，计算综合分和四维分数。
- **`services/report_service.py`**：调用上述 service，按月份 `groupby` 计算趋势数据，组装最终响应。

from pydantic import BaseModel, Field
from typing import List, Optional, Dict

class TransactionSchema(BaseModel):
    trade_date: str = Field(..., description="交易日, YYYY-MM-DD, UTC+8")
    summary: Optional[str] = Field(None, description="交易摘要")
    counterparty: Optional[str] = Field(None, description="交易对手")
    debit: float = Field(0.0, description="支出金额")
    credit: float = Field(0.0, description="收入金额")
    balance: float = Field(..., description="交易后余额")
    riskTags: List[str] = Field(default_factory=list, description="命中风险标签")

class MetricsSchema(BaseModel):
    income_total: float
    expense_total: float
    net_flow: float
    closing_balance: float
    avg_balance: float
    transaction_count: int
    cash_ratio: float

class ReportResponseSchema(BaseModel):
    summary: Dict
    metrics: MetricsSchema
    radarData: List[Dict]
    trendData: List[Dict]
    transactions: List[TransactionSchema]
