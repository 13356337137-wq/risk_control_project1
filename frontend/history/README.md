# 命名

```text
YYYYMMDD-NN.md      例：20261026-01.md

```

# 每条必须包含五段

| 段 | 内容 |
| --- | --- |
| 意图 | 这条需求想解决什么 |
| 改动 | 改了哪些文件，各一句话 |
| 验证 | 跑了哪条验收命令，结果如何 |
| 遗留 | 明确没做的部分 |
| 裁决 | 本轮有没有 PM/PD 裁决，引用 chat 里的原话 |

# 回滚

本目录只存**意图与说明**，代码回滚靠 git：

```text
每轮结束：git commit -m "task: <编号> <一句话>"
需要回滚：git revert <commit>

```

没有 commit 的改动，视为未完成。
